    Nextbot 2D Maker

    Turn an image into a 2D nextbot for Garry's Mod. Pick your image, set the name, size and sounds, and save the addon. Everything runs in your browser: your files never leave your computer.

    Requires DrGBase

    The nextbot will not work without it. Subscribe to DrGBase on the Steam Workshop.

    1. Image

    PNG, JPG, WEBP or animated GIF. A transparent background works best.

    For images with a solid color behind the character.

    2. Details

    A short code that makes your nextbot unique, so it does not clash with someone else's nextbot of the same character. Use the same tag for all your nextbots.

    3. Sounds

    All optional. MP3, WAV or OGG.

    Chase music (loop)
    On spawn
    On kill (jumpscare)
    Footsteps
    On death
    Idle taunt
    On hit

    4. Save

    Download the ZIP and unzip it inside garrysmod/addons. It is usually in C:\Program Files (x86)\Steam\steamapps\common\GarrysMod\garrysmod\addons.

    Save to a folder: Chrome and Edge do not let a web page write inside Program Files, where Steam installs Garry's Mod by default. This only works if your Garry's Mod is somewhere else, like a Steam library on another drive.

    Share it on the Workshop

    This page cannot publish for you: publishing needs Steam running on your computer. Use the tools that come with Garry's Mod (gmad and gmpublish, in the GarrysMod/bin folder) or gmpublisher. The README file inside the addon has the commands.
